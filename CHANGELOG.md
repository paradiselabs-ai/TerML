# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.4.1] - 2024-XX-XX

### Changed
- Updated dependencies to their latest versions:
  - anthropic from 0.7.4 to 0.36.0
  - click from 8.1.3 to 8.1.7
  - python-dotenv from 1.0.0 to 1.0.1
  - pytest from 7.3.1 to 8.3.3

## [0.4.0] - 2023-XX-XX

### Added
- Enhanced AI integration for more accurate and helpful responses
- Improved test generation with AI-powered suggestions
- New 'deps' command for managing project dependencies

### Changed
- Enhanced compatibility with the latest versions of httpx and httpcore
- Updated project structure and dependencies
- Improved error handling and logging
- Refactored code for better maintainability and performance

### Fixed
- All tests passing with the latest changes

## [0.3.0] - 2023-XX-XX

### Added
- Implemented 'analyze' command for code analysis and improvement suggestions
- Added 'generate' command for creating new project structures
- Introduced 'summarize' command for file and directory content summaries

### Changed
- Updated documentation to reflect new features and changes

## [0.2.0] - 2023-XX-XX

### Added
- Implemented 'auto' command for automated command suggestions
- Added 'chat' command for quick terminal-related Q&A sessions

### Changed
- Improved AI model interactions for faster response times

## [0.1.0] - 2023-XX-XX

### Added
- Initial release of TerML
- Implemented core features: explain, suggest, and debug commands
